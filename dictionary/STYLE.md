# 简体中文界面风格

面向 Cursor 智能体窗口。靠近 VS Code 官方简体中文语言包和 macOS 简体中文，不逐词对译。术语以 [GLOSSARY.md](GLOSSARY.md) 为准。

## 句子

- 按钮和菜单用动词开头：保存、关闭、重新启动、创建配置文件。不要「进行保存」「打开 MCP」这种缺宾语或套一层「进行」的说法。
- 一句英文对应一整句中文。日期、百分比、名字放进整句，不要先译半句再留半句英文。
- 少用「你的」。账户、密钥、隐私声明里需要指出是用户自己的数据时才用。设置说明里的 your workflow、your chat、your code 通常直接说工作流、聊天、代码。
- 人称用「你」，不用「您」。
- 被动能改成主动就改。「会被存储」可以，「被进行」不要。
- 模式名用中文，并且前后一致：计划模式、提问模式、智能体模式。斜杠命令 `/plan`、`/ask` 保持原文。
- 智能体还在工作时发消息，三个选项是「插话 / 排队 / 打断」。插话是不打断智能体、直接补充说明；排队是等智能体做完再发送；打断是停下智能体并发送这条消息。不要写成「转向」或「引导」。

## 标点和空格

- 中文句子用全角标点：，。：；！？、……
- 汉字和英文、数字之间加空格：`打开 MCP`、`已用 8%`、`Cursor 设置`。
- 日期写成 `10月24日`、`2026年10月17日 22:15`，月、日、年紧挨数字。`还剩 7 天` 这种句子里的数字仍加空格。
- 相对时间保持紧凑：`7小时`、`4分钟`、`13秒`、`26分钟前`。
- 引号用 “”，不用 「」 或贴着汉字的英文引号。正文括号用 （）。代码记号里的括号保持半角，例如 `render()`、`editor.update()`、`$(basename)`，不要写成 `render（）`。
- 同一概念只用一个词：侧边栏、身份验证、仪表盘、这台计算机、快捷键、提供程序、仓库、固定。标签页是 tab，标签是 tag 或 label。键盘快捷方式只用作菜单名。
- Failed to / Unable to / Could not / Cannot 用「无法」开头。保存失败一律「无法保存」。
- composer 译成聊天；后台 composer 和 Background Agent 译成云端智能体。Prompt 译成提示词，提示留给 Tips。Triage 用分类处理或排查。创建 PR 用创建或提交，打开只表示查看已有 PR。on a schedule 用定时或定期。窗格 / 平铺视图，不用磁贴。
- 产品名、协议名、斜杠命令、快捷键原样保留：Cursor、Slack、MCP、`/create-skill`、`shift+tab`、`⌘Enter`。

## 快捷键

- 词典里以 Ctrl / Alt / Shift 书写。
- macOS 上同一句会显示成 ⌘ / ⌥ / ⇧。运行时会生成这两种写法，译文里的修饰键跟着原文走。
- `ui-kbd` 里的键帽不翻译。

## 不要译的

- 模型名、品牌、Glass、Origin、Ultra。
- 编辑器正文、终端、差异行、聊天和模型输出。
- 屏幕顶部的 macOS 原生菜单。那部分用 VS Code 语言包 `MS-CEINTL.vscode-language-pack-zh-hans`。

## 错误和通知

- VS Code 核心文案优先采用官方语言包的简体中文（MIT，[vscode-loc](https://github.com/microsoft/vscode-loc)），再按上面的标点和「你」调整。
- 带 `{0}` 的错误整句翻译，不要只替换里面的一个词。
